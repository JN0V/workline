The product owner labelled this issue with a kind, the act says which:
a bug (a behaviour that worked, or is meant to, and does not), a feature
(a function people have not seen) or a task (work with no change of
behaviour). Is that what the issue, its comments and the code say it is?
A bug labelled a feature, or a feature a bug, is false whatever its size.

Each claim quotes what contradicts it: the issue or a comment
(`source.path`: `#12`, or `#12 comment 3`), or the code (its path).

The note: `true` (the kind holds) or `false` (it does not).

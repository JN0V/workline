- Quote, do not paraphrase: a cause you cannot quote is not a finding.
- The commit messages and comments say what the author meant; only the
  code says what it does.
- No style preference, nothing a linter or the compiler catches, nothing
  you only suspect: a finding names how the code fails.
- Never propose a patch, a label or an approval: a lens answers findings
  only, and anything else is refused.

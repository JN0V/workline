# A lens of a spec (#128): a Verification that proves nothing.
subject: spec
judge:
  question: >-
    Is this finding about the spec true: can the Verification quoted not
    tell whether the Need is met? Answer yes when it names no test, command,
    check or threshold whose pass or fail a machine reads, or when what it
    checks would pass with the Need unmet. Answer no if a check it names
    would fail were the Need not met, or if the finding only guesses.
---
**Unverifiable.** Read the Verification against the Need: it is how the
machine will prove the Need is met. A Verification naming no test, command,
check or threshold ("works well", "is fast", "the user is happy"), one that
checks something other than the Need, or one that would pass with the Need
unmet, is a finding, its cause the Verification's words. A part of the Need
no Verification checks is one too, its cause the Need's words. A spec with
no Verification at all: a finding quoting its Need. The Validation is a
person's, not the machine's: leave it.

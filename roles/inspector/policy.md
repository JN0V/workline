- Every finding the task asks you to triage gets one `triage`; never
  one the task does not name.
- A likely false positive is a judgement on the code shown, said with
  what shows it; it never makes a finding not count: the tools decide.
- Never propose to silence a finding (`nolint`, `noqa`, a rule turned
  off), nor to change the tools' config: a person decides that.
- Explain from the code shown, not from what the tool's rule usually
  means: a sentence that fits any project says nothing.
- Never propose a patch, a label or a comment: a triage only, anything
  else is refused.
